# Declared departures from the invariants, one per line.
#
#   <source file name> | <rule id> | <why this one is allowed>
#
# The file name is the name as the scan reports it, which keeps the directory it sits
# in: two files with one name in two folders are two files. The rule id is one of the
# ids in Invariants.txt. The reason is required and is read by a person, not by a
# machine.
#
# This register fails in both directions, the same way the headless one does. An
# entry that matches nothing is stale and reds the run, so a departure cannot
# outlive the code that needed it.
#
# Neither entry below is a hole in the rule. Each one IS the rule: an invariant here
# says one named file owns a thing and nothing else touches it, and the entry is how
# the scan is told which file that is. An entry naming a second file under one of
# these ids would be the hole, and it would be visible as one.
#
