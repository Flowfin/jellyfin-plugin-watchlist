Each user on this server gets a private watchlist, held on the server and readable by nobody else. Once the projection is built it appears in every client as a playlist owned by that user, so no client has to be changed, and adding or removing an item there is the same as adding or removing it from the list.

Nothing appears in a client today. What is built is the store the lists are kept in; the playlist projection and the endpoints are not, which is why no release is published. This paragraph is the answer to the first question an administrator asks after installing this, and it changes when the projection lands rather than before.

An add that would take a list past this is refused and nothing is written. Lowering it under a list that is already larger removes nothing: that list stops growing and says why. Ten thousand by default, which sits far above any list somebody curates by hand.
